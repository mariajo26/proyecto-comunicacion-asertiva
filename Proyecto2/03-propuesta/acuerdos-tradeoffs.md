# Acuerdos y Tradeoffs

## Acuerdos alcanzados

- **Acuerdo Uno:** El alcance inicial incluye el registro de productos y ventas, cálculo de totales, resumen diario, productos más vendidos y comparación de ventas por fecha.

- **Acuerdo Dos:** Se creará una propuesta técnica con interfaz sencilla, lógica de validación y base de datos relacional. La instalación y el motor de base de datos se definirán más adelante según costos, usuarios y conectividad.

- **Acuerdo Tres:** Se aplicará una matriz de pruebas para cálculos, persistencia, reportes, usabilidad y respaldos. Ninguna prueba se dará por aprobada sin haberse ejecutado primero.

- **Acuerdo Cuatro:** El cliente debe revisar los requisitos y definir el proceso para corregir o anular ventas, además de validar las reglas de precios y reportes.

- **Acuerdo Cinco:** Las funciones de inventario de ingredientes, planificación, pedidos especiales y desperdicios se reservan para una segunda etapa. Todo cambio de alcance requiere análisis previo.

- **Acuerdo Seis:** Cada actividad del acta tendrá un responsable y una fecha límite asignada. Los pendientes y defectos encontrados se evaluarán en la próxima reunión.

## Trade-offs considerados durante la reunión

**1. Entregar primero las funciones esenciales:** Se decidió priorizar el registro de productos y ventas y los reportes, dejando las funciones de inventario y planificación para una segunda etapa. El beneficio es desarrollar una primera versión más viable, aunque algunas necesidades del negocio no se resolverán inmediatamente.

**2. Priorizar la calidad sobre la rapidez de entrega:** Se acordó ejecutar pruebas de cálculos, reportes, persistencia y respaldos antes de aceptar el sistema. Esto requiere más tiempo de desarrollo, pero reduce el riesgo de errores y pérdida de información.

**3. Posponer la elección de la tecnología específica:** Se decidió definir más adelante la instalación y el motor de base de datos, tomando en cuenta costos, usuarios y conectividad. Esto permite elegir una solución más adecuada para la panadería, aunque retrasa la decisión técnica definitiva.

**4. Definir las reglas antes de implementar cambios en las ventas:** Se acordó que el cliente debe aclarar cómo corregir o anular ventas. Esto requiere tiempo adicional de análisis, pero ayuda a mantener la información y los reportes correctos.
