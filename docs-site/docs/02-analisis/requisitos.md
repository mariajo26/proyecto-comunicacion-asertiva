# Requisitos

Propongo estos requisitos porque buscan resolver problemas comunes en la administración de una panadería, como llevar el control de los productos, registrar las ventas manualmente y comparar los ingresos de distintos días.

## Requisitos funcionales

| Código | Requisito funcional |
|---|---|
| RF01 | Registrar los productos que vende la panadería. |
| RF02 | Registrar las ventas realizadas durante el día. |
| RF03 | Calcular automáticamente el total de cada venta. |
| RF04 | Generar un resumen de ventas al finalizar el día. |
| RF05 | Consultar los productos más vendidos. |
| RF06 | Consultar y comparar las ventas de días anteriores. |

## Requisitos no funcionales

- **RNF01:** El sistema debe ser sencillo de utilizar.
- **RNF02:** El registro de ventas debe realizarse rápidamente.
- **RNF03:** La información de las ventas debe conservarse para futuras consultas.
